# 我认为 ref14_3 应该怎么定义

现在应该第一次正式比较三条路线，而且参数、split、evaluation 尽量 matched。

### A. Direct Y

\[
\boxed{
(H,F)\rightarrow\hat Y
}
\]

### B. Physical bottleneck

\[
(H,F)\rightarrow(\hat E,\hat I)
\]

再：

\[
(H,\hat E,\hat I)\rightarrow\hat Y
\]

### C. Hybrid

\[
\boxed{
(H,F,\hat E,\hat I)\rightarrow\hat Y
}
\]

这里第一阶段的 \(F\) 我仍建议使用：

\[
F^{actual}
\]

作为 oracle action representation。

原因是先把：

> “给定真实 hand motion，Y 能不能预测到足够用于决策？”

证明掉。

暂时不要重新混进：

\[
joint\ action\rightarrow actual\ flow
\]

这个 execution 难题。
