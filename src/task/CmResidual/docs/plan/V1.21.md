# CmResidual V1.21：冻结单步 Cm 奖励的从零 DExplore 配对试验

- status: `final`
- work_version: `V1.21`
- task_mode: `change` → `experiment`
- approval_basis: 根目录 `AGENTS.md` 授权以 DExplore 环境从零训练策略，并允许重新设计 Cm 参与方式；本轮不使用官方 DExplore 策略 checkpoint。

## 假设

在完全相同的 DExplore 从零 PPO、reference、近接触 reset 和几何 approach shaping 下，冻结 Cmv2 对策略实际动作预测的单步物体位移进展奖励，能比 Cm-off 更快地产生稳定接触和抬升行为。

## 固定对照

- 两侧均为随机初始化策略，seed 42，不加载或蒸馏任何 DExplore actor checkpoint。
- 两卡同步 DDP；每卡相同 env 数、horizon、minibatch、PPO 参数与 `s1_airplane_lift` reconstructed baseline。
- 两侧均使用首次 reference contact 前后 `3/3` 帧 reset 和系数 `2.0` 的 potential-based approach shaping。
- 唯一研究变量：Cm-off 的 Cm 系数为零；Cm-on 加入固定 checkpoint/SHA 的冻结 Cmv2 单步位移进展奖励，系数 `1.0`。Cm 不进入 actor/critic observation，不更新参数。

## 阶段与门禁

1. 定向单测、语法检查、两卡 1-epoch smoke 通过后固定代码提交。
2. 先做小预算配对 pilot；两侧按顺序使用同一空闲 GPU 对，避免超过两卡上限。至少跨过一次从 contact reset 到 episode 终点，记录 TensorBoard episode reward/success、Cm 有效率、接触率和 checkpoint。
3. 任一侧出现 non-finite、OOM、traceback、DDP 不一致或 checkpoint 缺失即停止。pilot 只用于选择后续预算，不声称最终抓取或 Cm 因果效果。
4. 只有 pilot 显示可训练信号后才扩大 env/epoch；最终结论必须包含独立确定性评估和至少多 seed 的 Cm-off/Cm-on 对照。

## 已知限制

当前只覆盖 airplane 单轨迹 reconstructed baseline；近接触 curriculum 改变训练初态，但不改变最终评估初态。未完成的 V1.21c candidate-ranking 文件不属于本实验依赖或门禁。

## Pilot-1 后的冻结修正

Pilot-1 证明全近接触 reset 的策略在标准 Start 评估中两侧均为 0% lift，且 signed Cm reward 的负质量显著高于正质量。下一轮固定为两侧共享 `contact_fraction=0.5`，保留一半原始 Start reset；Cm-on 将 `tanh(Cm predicted improvement)` 截断到非负，只增加模型预测有益动作的探索 bonus。DExplore 原 reward 继续承担坏动作惩罚，其他配对变量不变。

Pilot-2/200 epoch 证明 positive-only Cm 能稳定增加接触和毫米级抬升，但仍未达到 3 cm，且训练后期退化。按 DExplore tensor 合同复核参考轨迹：首次接触为 frame 60，物体 z（原始 tensor 第 200 列）首次上升 3 cm 为 frame 79；旧诊断的 frame 403 来自误读人体关键点列 108，不能作为物体状态。下一轮两侧共享 50% Start、25% first-contact、25% lift-onset reset；lift onset 由任务加载后的 `motion["obj_pos"]` 在接触后相对累计最低点首次上升 3 cm 自动检测，不手写帧号。Cm 奖励形式和其他变量不变。
