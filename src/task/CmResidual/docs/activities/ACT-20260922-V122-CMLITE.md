## CmLite 模型

真实转移由 DExplore deterministic rollout 采集，schema 为
`ref2dex.cmlite_transition.v1`。seed 42/43 的 Cm-off 与 Cmv2 策略转移用于训练，seed 44
的两份转移只用于外部验证。总计约 16.1 万条转移、54 MiB。

CmLite 输入为 `q(18) + raw action(18) + object root state(13) = 49D`，预测物体坐标系
三维平移和接触概率。网络为 width 128、3 个 residual MLP block，共 107,012 参数；checkpoint
427 KiB。batch 64 CUDA 独立前向为 0.586 ms。

训练产物：
`outputs/CmLite/V1.22/train_s42_43_val_s44/best.pt`，SHA256
`d5de89b895d272e85ee72ee5ffddd76e6af3a4a0734115426074ad817c55bc52`。

离线留出集运动样本（真实位移 >0.5 mm）的 EPE 为 1.457 mm，零位移基线为
2.684 mm；接触 F1 为 0.737。完全未见的 seed-44 Cmv2 转移上，运动 EPE 为
3.183 mm，零位移基线为 3.477 mm。静止样本存在约 0.4--0.5 mm 偏置，因此不能直接把
预测接触当作可靠门控。

动作审计中，把同批动作打乱后，seed 42/43/44 的预测位移平均变化分别为
1.623/0.488/0.425 mm；模型没有退化成只看状态的 predictor。

## RL 接入与吞吐

奖励使用 CmLite 预测位移对下一参考物体位置误差的改善，保持 positive-only，并用仿真当前
真实手--物接触门控，避免策略利用接触分类误报。系数 5 用于匹配旧 Cmv2 系数 1 的实际奖励量级。

相同 2x32 env、horizon 32 配置，忽略前 9 epoch 后的中位吞吐：

| 分支 | step FPS | total FPS |
| --- | ---: | ---: |
| Cm-off V1.21 | 340.9 | 296.2 |
| Cmv2 V1.21 | 200.4 | 182.6 |
| CmLite fixed curriculum | 295.4 | 263.8 |
| CmLite annealed curriculum, 200 epoch | 313.0 | 277.4 |

CmLite 相对旧 Cmv2 的 total FPS 提升约 52%，相对 Cm-off 的差距约 6.3%；这解决了原
Cmv2 在 PPO 前向中的主要吞吐问题。

## 后续优先级

1. 增加廉价的 wrist/object 相对位姿、指尖到物体距离和预计算 object shape embedding；当前
   49D 输入没有显式手--物几何或物体身份，不足以支撑多轨迹/多物体泛化。
2. 每 10--20 epoch 保存 checkpoint，并用独立验证环境的物理接触/抬升指标选择，而不是训练 reward。
3. 在新 seed 上做 annealed Cm-off/CmLite 成对实验；目前 curriculum 改动没有匹配 Cm-off，不能把
   seed-44 的 2.8 cm 全部归因于 Cm。
4. 先达到至少 3 个训练 seed 的稳定严格成功，再扩到更多 GRAB 轨迹和 MANO retarget 数据。
