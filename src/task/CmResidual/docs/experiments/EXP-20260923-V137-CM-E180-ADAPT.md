## 问题与固定方案

V1.36 的 e180 自训练策略 seed78 有 32/64 严格抓取，但 V1.34
CmLite 在其真实运动转移上仅比零位移低 18.6%，未过20% 的
动作选择预检。测试是否加入**后期成功策略**的转移，可以使
仍然 49D/107,012 参数的 CmLite 在未见 seed 上达到可靠门槛。

训练源固定为 V1.34 五源，另加入 s3 Cm-off e180 策略
seed78 的**首 episode 非终止**转移；没有官方 checkpoint。
为了避免新 s3 数据再次稀释 s1，两份 s1 DAgger 源只在内部
holdout 划分后各重复24次，其余四份 s3 源各一次；内部 holdout
保持唯一。其余结构/特征/优化器仍为相对手腕 CmLite、30 epoch、
batch2048、AdamW `3e-4`、seed42。训练只占 GPU6，产物预计
小于100MB。

独立门禁：同一自训练 s3 e180 策略的新 seed79、64 env 首
episode 非终止转移；模型运动 EPE 比零位移至少低20%，打乱
动作后运动 EPE 增加至少10%，接触 precision ≥0.5。
s1 DAgger seed5909 运动 EPE <零位移，并在另一新 s1 PPO
e140 seed77 的高抬升分布上运动 EPE <零位移。seed5909 已
用于选择平衡方向，不作独立确认；s1 PPO seed77 才是新
跨轨迹复核。全部通过才允许新动作选择器试验，未过则停
该追加数据方案并检查缺失手部速度/接触状态等特征。

两条独立转移评估各一次，占 GPU5/6 且同时最多两卡；不更新
评估策略。输入、训练源、checkpoint 与转移都固定 SHA，
异常或外部占卡即停。离线一步预测通过仍不证明在线收益。
