- branch: `agent/multitrajectory-v129`
- run_status: `COMPLETED`

- official actor checkpoint used: `no`

## 问题与固定方案

V1.36 的 e180 自训练策略 seed78 有 32/64 严格抓取，但 V1.34
CmLite 在其真实运动转移上仅比零位移低 18.6%，未过20% 的
动作选择预检。测试是否加入**后期成功策略**的转移，可以使
仍然 49D/107,012 参数的 CmLite 在未见 seed 上达到可靠门槛。

训练源固定为 V1.34 五源，另加入 s3 Cm-off e180 策略
seed78 的**首 episode 非终止**转移；没有官方 checkpoint。
为了避免新 s3 数据再次稀释 s1，两份 s1 DAgger 源只在内部
holdout 划分后各重复24次，其余四份 s3 源各一次；内部 holdout
保持唯一。其余结构/特征/优化器仍为相对手腕 CmLite、30 epoch、
batch2048、AdamW `3e-4`、seed42。训练只占 GPU6，产物预计
小于100MB。

独立门禁：同一自训练 s3 e180 策略的新 seed79、64 env 首
episode 非终止转移；模型运动 EPE 比零位移至少低20%，打乱
动作后运动 EPE 增加至少10%，接触 precision ≥0.5。
s1 DAgger seed5909 运动 EPE <零位移，并在另一新 s1 PPO
e140 seed77 的高抬升分布上运动 EPE <零位移。seed5909 已
用于选择平衡方向，不作独立确认；s1 PPO seed77 才是新
跨轨迹复核。全部通过才允许新动作选择器试验，未过则停
该追加数据方案并检查缺失手部速度/接触状态等特征。

两条独立转移评估各一次，占 GPU5/6 且同时最多两卡；不更新
评估策略。输入、训练源、checkpoint 与转移都固定 SHA，
异常或外部占卡即停。离线一步预测通过仍不证明在线收益。

## 结果与边界

seed78 e180 源筛选后 33,053 条首 episode 非终止转移，加入
原五源训练；30 epoch 正常完成，checkpoint
`outputs/CmLite/V1.37/balanced_s1x24_s3_e160_e180/best.pt`，SHA256
`396f5e0c92ecf67b2a096568c1a538b7c86d40779a594729f786df6c64ed204a`。
参数仍为 107,012，64 样本 GPU 前向约 0.555 ms。

全新 seed79 的 s3 Cm-off e180 策略完整轨迹抓取 42/64，
首 episode 非终止转移 33,180 条；模型运动 EPE **5.294 mm**，
零位移 **8.896 mm**（改善40.5%），固定状态打乱动作后
**7.769 mm**（比真实动作高46.8%），真实动作接触 precision
**0.929**。s1 DAgger seed5909 运动 EPE **1.872 / 3.311 mm**，
全新 s1 PPO e140 seed77 为 **19.973 / 20.328 mm**。
四项预注册门槛均通过，但 s1 PPO 高抬升分布的优势仍只有
0.355 mm（1.7%），不能视为强跨轨迹泛化证明。

seed79/s1 seed77 的评估 manifest 各记录策略、输入与转移
SHA；`cmlite_audit_v137.json` 记录模型 SHA 和离线指标。
本实验只允许下一轮冻结策略/模型的在线动作选择测试，
不能直接宣称 Cm 提升抓取。
