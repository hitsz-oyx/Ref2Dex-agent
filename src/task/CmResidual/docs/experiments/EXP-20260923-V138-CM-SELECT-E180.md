## 固定方案

V1.36 对 V1.34 模型的 e180 策略 seed78 预测预检只改善18.6%，
按规则没有运行选择器。V1.37 加入 e180 成功策略 seed78 的训练
转移后，在独立 seed79 改善40.5%，动作打乱与 s1 保留门槛也
通过。本实验重新检验**冻结模型的执行期五候选选择**，而非
PPO 奖励。

策略仍冻结为自训练 s3 Cm-off e180，SHA256
`863443513a746155f2b04662fe4dddd8c7b5a672d3e73533c1ff555d90c0237c`；
模型改为 V1.37 平衡 CmLite，SHA256
`396f5e0c92ecf67b2a096568c1a538b7c86d40779a594729f786df6c64ed204a`。
其他设计完全沿用 V1.36：原策略动作和腕 z±0.01、六指+0.04、
腕 z+六指四种小扰动，归一化动作夹到[-1,1]；按预测下一
物体位置相对参考目标的进展×预测接触概率评分，预测接触
阈值0.25，真实手物接触连续至少5步后才允许替换；原动作
始终是 fallback。不更新策略或 CmLite。

先在**新 seed80** 对原策略跑64 env完整轨迹/无提前终止首
episode 基线并保存转移。若模型运动 EPE 未比零位移至少低
20%，或固定状态打乱动作后 EPE 未高至少10%，立刻停止。
通过后在同一 seed80、同一策略、同一输入评估选择器。
pilot 要求严格成功至少比原策略多3/64，且同环境配对修复
多于破坏，才在未见 seeds81–83 各做64 episode成对复评。
跨 seed Cm 增益要求每 seed 选择器严格成功高于原策略且
合计至少多10/192；s3 稳定抓取另要求每 seed ≥90%。
seed80 只用于预检与 pilot，不能作为未见泛化证据。

同时记录候选替换率与评估壁钟时间，关注延迟；不以微小
速度差代替抓取结果。最多两GPU、优先单 GPU5 顺序运行，
源 SHA/input schema 漂移或异常立即停。总产物预计<1GB。

## 结果与预注册停损

seed999 只作接线 smoke，正常完成，不以其抓取指标决策。
新 seed80 的原策略首 episode 严格抓取 **31/64**，模型
预检运动 EPE **4.767 / 零位移 7.875 mm**（改善39.5%），
固定状态打乱动作后 **6.962 mm**（比真实动作高46.1%），
通过两项上线预检。相同策略、seed、轨迹和完整 episode
口径下，五候选选择器只抓取 **27/64**。

按 `env_id`、`start_frame`、`motion_id` 严格配对，选择器修复
原失败 **12** 个、破坏原成功 **16** 个，净损失4/64。
19.0% 的首 episode 步执行了非原策略动作；评估器记录的
壁钟时间为 baseline **46.029 秒**、选择器 **47.161 秒**
（约+2.5%，仅单次测量，不视为稳健延迟估计）。pilot 未达到
多3/64且修复多于破坏的双重门槛，故**不运行 seeds81–83**。

这否定当前五候选、单步参考目标进展、稳定接触门的选择规则，
不否定冻结 CmLite 的一步运动预测：离线预检已通过，但
局部贪心评分没有转化为闭环成功。12 个修复也说明存在
可利用信号；未来若改用不确定度、价值评估或整段一致性
约束，应重新预注册并保持同环境配对比较。

原策略/选择器的 `eval_s80_e180_full{,_cmselect}/results.json`
与各自 `run_manifest.json` 保存 64 环境结果、SHA 和精确命令；
原策略目录另有转移与 `cmlite_audit_v137.json`。
