## 核心问题与固定设计

V1.41 的 CmLite 一步选择虽在筛选 seed90 多5/64，
在未见 seeds91–94 仅比不干预多2/256并于 seed93
损失5/64。V1.42 发现冻结模型在真实接触转移上有
一步预测信号，但**观察数据上的 EPE 不能证明它
能正确排序相同状态下的两个候选动作**。

冻结 V1.40 整段路由 SHA256
`7db4686f8eb273e0ac94bfbbd3625ddd35209a1f4922e8451bcbf519f6395a79`、
三枚自训练 PPO、V1.37 CmLite SHA256
`396f5e0c92ecf67b2a096568c1a538b7c86d40779a594729f786df6c64ed204a`。
新 seeds97、98，每 seed 各运行原路由 `off` 与
V1.41 `always` 一次，64环境首个完整 episode，
提前终止关闭。在两臂第一次达到“真实手物接触
连续5步且物体相对初始高度<6cm”的**干预前**，
记录同环境 q、物体13维状态、原动作、加0.08
手指动作、下一目标位置及执行后下一物体状态。
在首次干预前两臂本应执行完全相同动作；只有
起始帧、运动编号、进度相同，且 q 与原动作最大
绝对差均≤1e-4、物体位置差范数≤1e-5m、13维
物体状态最大绝对差≤1e-4 的成对样本才
作同状态反事实。若两 seed 合计不足40对，或
任一 seed 少于15对，则判定物理匹配不可用，
不解读 Cm 排序。

对匹配对，实际一步反事实效应定义为
`next_object_xyz(always) - next_object_xyz(off)`；
Cm 预测效应为相同 off 干预前状态下两候选的
`delta_world` 之差。先报告实际效应范数分布。
若实际效应>0.2mm 的 informative 对合计少于20，
说明一步物体变化太小，本审计对动作排序无鉴别力；
应研究多步 Cm 而非声称模型排序失败。
否则门槛为预测效应 EPE 相比零效应基线至少低20%，
且投影到下一参考目标方向后的效应符号一致率≥60%。
未过则 V1.37 CmLite 不适合直接门控这个候选；
通过也仅证明一步局部因果效应近似，不证明抓取率提升。

审计不用真实结果作为运行时输入，不训练策略或 Cm。
最多并发GPU5/6两卡；运行代码、配对文件与来源
SHA 记录在 manifest，产物远低于300GB。

## 结果与因果限制

四个完整回合均正常结束，各臂64/64环境记录了
首次满足干预条件的状态。seed97 的 off/always
严格抓取分别45/48，seed98分别49/45（分母均64）。
seed97 两臂并发 GPU5/6；为排除跨卡差异，seed98
在同一 GPU5 顺序执行。但首次干预前配对结果为：

| seed | 共同 env | 同进度/元数据 | 严格同状态 |
| ---: | ---: | ---: | ---: |
| 97 | 64 | 36 | **1** |
| 98 | 64 | 36 | **0** |

干预前同一 env 的物体位置均值差约6–7mm，远大于
本审计欲分辨的0.2mm效果；同 GPU 顺序执行仍未
消除。只有1个有效样本，远低于预设总计40、每
seed15的最低配对数，因此**不计算或解释 Cm 的
反事实动作排序门槛**。唯一有效对的数值不具统计
意义；审计 JSON 仅保留供复现。现有证据不能区分
模拟器非确定性、未记录的初始状态差异或其他运行
因素，需下一轮重跑同一 `off` 策略审计重现性。

这还限制 V1.40/V1.41 中按相同 env_id 的“修复/
破坏”描述：相同起始帧不等于同一中途物理状态，
不能把那些数字解释为逐环境动作的因果效应。
跨 seed 聚合成功率仍是策略表现的描述性比较，
但差异显著性需要更多重复及噪声基线。
