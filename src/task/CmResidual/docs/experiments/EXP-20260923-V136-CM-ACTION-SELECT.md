## 假设与固定设计

V1.30 与 V1.35 的预测进展奖励都显著落后匹配 Cm-off；
V1.34 离线模型却能在高抬升策略转移上预测动作相关物体运动。
本实验改为**冻结策略和模型，只在执行时让 CmLite 从局部
动作候选中选择**，隔离 PPO 奖励优化的影响。

冻结自训练 s3 Cm-off e180 PPO checkpoint
`agent_v135_s3_cmoff_s70_e180/GRAB_00000180.pth`，SHA256
`863443513a746155f2b04662fe4dddd8c7b5a672d3e73533c1ff555d90c0237c`；
CmLite 仍为 V1.34 平衡模型，SHA256
`1146025ca88b35f39a5fad7f5f899a88cca34b774fa9abe0c0d6f5d72519e1b8`。
不更新任何权重。每步固定五个动作候选：策略原动作、腕 z
正/负 `0.01`、六个主要手指关节加 `0.04`、腕 z 加手指加；
均在 DExplore 归一化动作域夹到 [-1,1]。使用已有
`select_cmlite_action` 的一步目标进展乘预测接触概率评分，
预测接触阈值 0.25，仅在真实手物接触连续至少五步后允许
替换；原策略动作为永远可用的零号 fallback。目标仍用下一
参考帧物体位置。该选择器没有训练/试探真实后果的权限。

先在新 seed78 对同一策略做 64 env、完整轨迹、提前终止关闭的
Cm-off 基线并保存转移；离线审计 V1.34 模型。若运动 EPE 未比
零位移低至少20%或打乱动作后 EPE 未升至少10%，停在该
分布外门禁，不上线选择器。通过才在**同一 seed78** 评估固定
选择器，对比严格成功数、同环境配对修复/破坏、替换率和
评估耗时。pilot 至少多 3/64 严格成功且修复数多于破坏数，
才冻结方案在未见 seeds79–81 各复评64 episode；否则停损。
跨 seed 的 Cm 在线收益要求三个 seed 每个选择器高于原策略、
合计至少多10/192；稳定 s3 抓取另需每 seed ≥90%。
seed78 既用于离线预检和 pilot，不作为未见泛化证据。

基线与选择器依次占一张空闲 GPU 5，最多两 GPU 总上限；
每轮保留模型/策略/输入 SHA、命令与结果，所有产物预计 <1GB。
发现占卡、SHA 漂移、选择器异常或 episode 口径不一致即停。

## 预检结果与停损

新 seed78 的自训练 Cm-off e180 策略在完整轨迹门禁为 32/64；
33,053 条首 episode 非终止转移中，V1.34 冻结 CmLite 的
运动 EPE 为 **6.2965 mm**，零位移为 **7.7348 mm**，改善
**18.6%**，未达到预注册的至少 20%。固定状态打乱动作后的
运动 EPE 为 7.3143 mm，比真实动作高 16.2%，这一项通过；
接触 precision 为 0.899。由于预检是联合条件，仍触发
停损。**没有实现或运行在线选择器，也没有评估 seeds79–81**；
因此本实验不能判断选择器是否有益，只说明当前模型在 e180
分布上的运动预测未达到既定上线可靠性门槛。

基线 `eval_s78_e180_full/run_manifest.json` 记录策略/input/转移
SHA、完整轨迹口径和 32/64；`cmlite_audit_v134.json` 记录
模型 SHA、首 episode 筛选与全部离线指标。下一步需显式
适配 e180 成功策略分布，另用全新 seed 复核，不能把 seed78
重新用作独立门禁。
