## 单一工程决定与无法自证处

结论是**混合机制，H1的接触负载/有限刚度部分 + H2动态带宽均有证据**；H1“≥20mm竖直下垂”、H2“静止几乎零”、H3“固定映射偏置”、滑移主导都不能作为唯一解释。33.267mm是45格的P95中位，静态10–17mm来自一个端点，不能用33−10或方差相减伪造各机制百分比。

**唯一下一步：给原TRACK加入实测物体SE3稳态校正（限幅积分、抗饱和，保留既有FF与PD），先把同端点加载稳态位置10–17mm降到≤5mm、姿态2.4–4.2°降到≤2°。** 这是拟议验收数，不是本轮已实现；未改任何增益/默认配方，不直接进入训练。理由是卸载同状态近零、加载出现可重复的静态地板，单纯加速度前馈在v=0严格为零，继续调它不能消掉该项。动态仍有斜率，静态件通过后再决定带宽件；不同时改多个因素。

本轮无法自证：关节实际驱动力与负载的子步因果分解；gravity-only vs contact-only；其它目标/物体；自碰撞（原过滤关闭，不能认证无碰撞）；同模型执行/强化学习效果（本轮未用模型）。配对3组是机制探针，不提供泛化或成功率置信区间。最大新静态漂移/安全数据保留在所有ticks，不删除过渡不利帧。
