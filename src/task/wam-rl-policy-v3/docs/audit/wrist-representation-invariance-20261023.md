### 统计与解释

* 2π 等价变换：`0/21` 改变守卫判定，改变比例 `0.0%`；`21/21` 仍为 ABORT。
* 同一重放同时检查 4π 周期口径（复用 brief44 的冻结重放）：也是 `0/21` 改变守卫判定。
* PD 误差：`0/21` 向量改变；所有 `e'=e`（数值误差容差 `1e-12`）。没有出现 PASS→ABORT、ABORT→PASS，也没有非物理 PD 误差突变。
* 这次门读数变化来自原本手指受限 DOF 的终止跨界；腕 q 的等价平移不进入 `hasLimits` mask。因而“腕角跳变与中止共现”不能在本静态测试中被识别为中止成因，也不排除它作为物理冲量或驱动异常的伴随症状。

## 单一裁决

**REFUTED（针对“腕角表示不一致直接造成关节门误判”的代码级假设）。** A 证实 joint4/5/6 是连续、无位置限位的 DOF，等价表示合法；B 在 21 个既有中止上显示，统一 q 与 q_target 的等价分支后，守卫判定和 PD 误差完全不变。因此不派“只修腕角表示 + 单臂 n=5”修法，不改门阈、不改 PD 增益、不改执行器参数。

这不是对因果机制的过度结论：当前存档仍缺 native 物理子步内的 drive target/error、约束/驱动冲量、成对接触几何与冲量，以及 SDK 内部实际 wrap 行为。它们只能作为下一条因果诊断的字段申请，不能由本轮离线门重放补出。
