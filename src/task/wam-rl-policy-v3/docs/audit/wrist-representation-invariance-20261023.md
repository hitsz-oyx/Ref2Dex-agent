## B. 等价表示重放协议

输入限定为 brief44 已列出的 21 个 `physical_joint_limit` 终止回合。对每个回合令 `t` 为第一次关节门中止的 state tick，读取已存 `q[t−1]`、`q[t]` 与实发 `pd_targets_actual[t−1]`。不重建 brief44 的死因计数，不调用 `collect.py`，不启动 native host。

对每个腕轴用已存 q 序列计算 period=`2π` 的统一分支（另以 `4π` 做敏感性复核）。在比较状态 `s∈{t−1,t}` 上使用同一坐标变换：

```text
q′[s]        = q[s] + 2π n[s]
q_target′[s] = q_target  + 2π n[s]
e′[s]        = q_target′[s] − q′[s] = e[s]
```

这里 `n[s]` 是该状态在统一参考系中的整数分支；所以 target 与 q 在同一状态比较时同步平移。守卫重新读取同一个 finger/prismatic 状态，腕 3:6 仍被 `hasLimits` mask 排除。报告表中的 `G_R` 是受限手指关节的最大 guard read，定义为 `max(lower−0.10−q, q−upper−0.10)`；`G_R>0` 才是关节门触发。PD 误差列依次为命令时刻 `||e[t−1]||` / 中止状态 `||e[t]||`。
