# BC/PPO 机制诊断：策略位移与奖励信号

本报告只分析已经保存的配对运行，不重新采样、不启动物理、不修改默认配方。源运行是预算缩小后的 14,400 controls/arm；B1 使用 BC 起点 `drift-intent-residual-20261022-r1/bc/bc.pt` 与主训练末态 `bc-ppo-usefulness-20261023-r1/ppo/residual-final.pt`，B2 使用 36 个 PPO episode 的 `ppo-rollout.npz`、`reward-parts.json`，并用同一 episode 的 `stages.json` 对齐认证接触/抬升/持握状态。

## 结果解读表

| 可能结果 | 实测数字 | 含义 | 决定 |
|---|---|---|---|
| 位移/残差尺度很小且无正样本 | 全 12D 归一化 `|Δa|/scale`：均值 **0.01031**、P95 **0.04560**、最大 **0.17827**；认证接触/抬升/持握并集 **2,270/14,400 = 15.76%**；正 event reward **25/14,400 = 0.174%** | 大多数控制步的策略位移较小，但不能写成“完全没动”，且存在少量接触及成功前状态；0/6 不能单独解释为 PPO 无用 | 不把本轮定性为 PPO 无效；若继续，需在补预算和先修奖励/价值配比之间做裁决。本轮不启动长训练 |
| 位移/残差尺度很大但成功率无变 | 未观察到 `≫0.3`：三个配方组的 P95 分别为平移 **0.07686**、腕旋 **0.05020**、手指 **0.00709**；最大值分别 **0.17827/0.13861/0.01319** | 没有“策略被显著推开却完全不改善”的证据；执行链瓶颈仍可能存在，但不能由 B1 单独确认 | 保留 0/6 与 BC 0/6 的执行链疑点，暂不把它升级为本次机制结论 |
| 有正样本但优势被 bootstrap/惩罚淹没 | 接触并集 **15.76%**，lift **10.18%**，hold **9.56%**；优势绝对值账本中 value TD **85.58%**、bootstrap **1.76%**（相对总 `|A|` 为 **1.99%**），reward 项合计 **12.66%** | 正样本存在但事件奖励很稀疏；主要问题更接近 critic/TD 项尺度与稀疏事件的配比，不是 bootstrap 主导 | 先量化并修正奖励/优势配比，再决定是否补预算；本轮不改默认配方 |
| lr×100 仍只有约 1e-3 级 KL | 保存批次上单步重算：10× lr 的 KL 中位数 **0.02031**、P95 **0.09895**；100× 为 **0.12444/5.20785**，最大 **56.36** | 学习率上限不是极低；10× 已达到目标 KL 附近，100× 会越过 KL 门很多 | 加预算不能作为唯一优先动作；若继续，先处理信号/优势尺度与 KL 配比，不直接把 lr 改成 10×/100× |

因此，`0/6 vs 0/6` 不是“PPO 无效”的证据。更准确的机制描述是：策略经过 72 次更新后有小幅、非均匀的累计位移；数据中存在接触/抬升/持握正状态，但真正的 event/sparse reward 极少，GAE 的绝对量级主要由 value TD 项构成。预算不足仍是可能因素，但不能跳过信号质量诊断直接归因于预算。

## B1：策略位移相对残差尺度

### 口径

对同一批已保存的 PPO 观测逐控制前向，比较两个 checkpoint 的 Normal 分布均值 `μ`。动作位移定义为：

```text
Δa = tanh(μ_PPO) * scale - tanh(μ_BC) * scale
normalized = abs(Δa) / scale
scale = [10 mm × 3, 40 mrad × 3, 30 mrad × 6]
```

以下聚合覆盖 14,400 个保存观测；平移、腕旋、手指分别按各自配方尺度归一化。表中是控制步/维度上的绝对值统计，不是 KL。

| 组 | 均值 `|Δa|/scale` | P95 | 最大值 |
|---|---:|---:|---:|
| 平移 / 10 mm | 0.019193 | 0.076859 | 0.178267 |
| 腕旋 / 40 mrad | 0.016019 | 0.050199 | 0.138607 |
| 手指 / 30 mrad | 0.003005 | 0.007094 | 0.013187 |
| 全 12D | 0.010306 | 0.045598 | 0.178267 |

六个固定初态（合并其在 36 个训练 episode 中出现的保存观测）的全 12D 结果如下；`controls` 是实际保存的观测数，因物理早停不同而不等于 6×600。

## B2：奖励、优势和正状态信息量

### 奖励分布

统计覆盖 36 个 PPO episode、14,400 个 control 步。每步总 reward 的统计为：均值 **−0.001544**、标准差 **0.036751**、P01 **−0.003375**、P05 **−0.002058**、中位数 **−0.000892**、P95 **−0.000519**、P99 **0.006648**、最小 **−1.001326**、最大 **0.999419**。因此大多数步是小幅负值，尾部由少数阶段/终止事件拉出接近 ±1 的值。

| 分项 | 均值 | 标准差 | 正值步数 | 非零步数 |
|---|---:|---:|---:|---:|
| shaping | 0.0002815 | 0.0053509 | 282 | 282 |
| event | 0.0002083 | 0.0052663 | 25 | 25 |
| sparse | −0.0009722 | 0.03534197 | 2 | 18 |
| time | −0.0003333 | 约 0 | 0 | 14,400 |
| effort | −0.0007285 | 0.0005456 | 0 | 14,400 |

`event` 正样本仅 **25/14,400 = 0.174%**；`sparse` 正值仅 **2/14,400 = 0.014%**，另有 16 个非零负 sparse 终止项。`shaping` 只有 **1.96%** 步为正。

### 优势分布与谁主导梯度尺度

按运行配方 `gamma=.96`、`GAE lambda=.95`，从保存的 `rewards`、`values` 和每 episode 保存的 bootstrap 重算 raw GAE；PPO 实际使用的 normalized advantage 则逐 episode 标准化。

- raw advantage：均值 **−0.059045**、标准差 **0.290159**、P01 **−0.845451**、P05 **−0.517966**、中位数 **−0.042587**、P95 **0.417678**、P99 **0.709366**、范围 **[−2.016768, 1.331487]**。
- episode 内标准化后汇总：均值 **0**、标准差 **1**、P05 **−1.5240**、中位数 **−0.0847**、P95 **1.6931**、P99 **3.1175**、范围 **[−5.5656, 7.5569]**。
- reward 项的 GAE 绝对量（只把每个 reward 分项单独通过 GAE 传播）在 reward-only 账本中的占比：`sparse 45.17%`、`effort 25.49%`、`time 11.74%`、`shaping 10.12%`、`event 7.48%`。这是线性 GAE 项的尺度分解，不是因果归因。
- 将 reward、value-TD、bootstrap 三类线性项分开后，绝对量账本为：reward 项 **452.45**、value-TD **3,059.49**、bootstrap **63.08**，分母 **3,575.02**。对应占比为 reward **12.66%**、value-TD **85.58%**、bootstrap **1.76%**。相对于最终合成 advantage 的 `sum(abs(A))=3,174.02`，bootstrap 的比值为 **1.99%**。

结论是 bootstrap 没有淹没梯度；更突出的现象是 critic/value-TD 项在绝对尺度上远大于直接 reward 项，而可识别的 event/sparse 正奖励又非常少。`return_mean` 与 `target_return_mean` 的量级/符号差异因此不能只用“随机噪声”解释，也不能把 normalized advantage 的标准差 1.0 当作原始信号有信息量的证明。

### 认证接触/抬升/持握状态

使用每 episode `stages.json` 的 `stages[1:n+1]` 与每步 reward/control 对齐，统计 action 后的认证状态：

| 状态 | control 步数 | 占 14,400 步 | 有该状态的 episode |
|---|---:|---:|---:|
| contact | 2,270 | 15.764% | 11/36 |
| lift | 1,466 | 10.181% | 3/36 |
| hold | 1,376 | 9.556% | 3/36 |
| contact ∪ lift ∪ hold | **2,270** | **15.764%** | **11/36** |

`lift` 与 `hold` 都是 `contact` 的子集，因此并集不是三行简单相加。认证正状态并非约等于零，但它集中在少数 episode；稳定最终成功仍只在随机训练采样中见到 2 个 episode，确定性六初态终点评估仍为 0/6。

## B3：保存批次上的单步灵敏度上界

这是纯离线的内存重算：从 BC checkpoint 开始，按保存的 36 个 PPO batch 顺序计算 72 个 optimizer 单步候选（每 batch 两个 epoch），不启动物理、不写 checkpoint、不执行 KL rollback。每个候选的 exact-KL 是该步前后 12D Normal 在该保存 batch 上的平均精确 KL；残差位移是该步 batch 内 `mean(|Δa|/scale)`，再在 72 个候选步上汇总。因此这里的 P95 是“候选步统计量”的 P95，不是把所有控制点混在一起的控制点 P95。

| lr 相对当前值 | exact-KL 中位数 | exact-KL P95 | exact-KL 最大值 | 全 12D `mean(|Δa|/scale)` 均值 | P95 | 最大值 |
|---:|---:|---:|---:|---:|---:|---:|
| 1× (`1e−5`) | 0.000274 | 0.000837 | 0.005772 | 0.000228 | 0.000389 | 0.000956 |
| 10× (`1e−4`) | 0.020314 | 0.098945 | 0.577562 | 0.002108 | 0.004136 | 0.009566 |
| 100× (`1e−3`) | 0.124443 | 5.207850 | 56.356724 | 0.008484 | 0.026384 | 0.094670 |

10× 与 100× 的三组残差尺度归一化位移（均值 / P95 / 最大值）为：

| lr | 平移 / 10 mm | 腕旋 / 40 mrad | 手指 / 30 mrad |
|---:|---:|---:|---:|
| 10× | 0.004186 / 0.009247 / 0.019231 | 0.003350 / 0.007370 / 0.016553 | 0.000449 / 0.000809 / 0.001239 |
| 100× | 0.016398 / 0.055928 / 0.192189 | 0.012864 / 0.040010 / 0.161682 | 0.002337 / 0.006823 / 0.012405 |

B3 不支持“把 lr 提高 100× 仍只有约 1e−3 KL”的解释；相反，100× 在保存批次上会频繁越过当前 `.03` exact-KL 门。它说明学习率确实能推动策略，不能说明提高学习率后闭环会成功。
