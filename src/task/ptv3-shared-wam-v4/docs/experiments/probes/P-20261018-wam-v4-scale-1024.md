# WAM-v4 1024-width capacity probe

This probe changes only the shared transformer width from 768 to 1024 and the
number of attention heads from 12 to 16. The point/query counts, PTv3 geometry,
objective, data recipe, validation panel, seed, and per-GPU batch remain fixed.
The resulting model is approximately 166.0M parameters versus 98.7M for the
current run. The 768-width checkpoint is not used because the checkpoint
contract requires exact shared architecture identity; this run starts from
fresh weights.

The current 768-width run must reach a terminal `COMPLETED` state before this
probe is launched. A short four-GPU startup smoke and GPU-memory check precede
the long run. This is an offline pretraining Probe; it does not establish robot
control benefit.
