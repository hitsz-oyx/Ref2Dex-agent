## Frozen method

future24steps=.8s. All positions use C=inverse(T_anchor,t), unchanged across
history, action and effect. Select annotated local objects by current transformed
mesh surface centroids,<=0.5m; never future position. Keep both hands/right-first,
11fixed semantic points, validity masks, reject jumps/gaps;512canonical surface
points/object with normals. Loss vector-L1 translation +RMS-radius×geodesic
rotation +vector-L1 analytical point correspondence, weights1/1/1.

A H→E; B H+A→E; C H+shuffle(A)→E independently trained. Same seed211,
initial parameters, split,index draw schedule,effective batch16,40000updates,
AdamW3e-4/wd.01,400warmup,cosine to.1LR,gradclip1,bf16dense/float32sparse.
Shuffle entire action features and masks within hand-presence groups. Singleton
microbatch groups use a different sampled training donor with matching presence;
no unchanged recipient is silently counted as shuffled. Validation/test donors
come only from their respective split. Full action chunk attention is noncausal.

Sampling60%any-horizon anchor motion (>2mm OR>.02rad),20%small effect with
current program/proximity cue,20%small effect without those cues. Metadata
strata are not model input. Train/val/test hashes(seed210)split by sequence,
80/10/10 target proportions. Split object/scene/action-prefix overlaps are audited;
this is not guaranteed unseen-object or unseen-subject evaluation.

## Limitations / future evidence

Observed future hand motion is post-treatment supervision, not a commanded
counterfactual intervention. Human dynamics accuracy alone does not prove
robot or PPO utility. One seed and shared objects/prefixes cannot establish
statistical or domain generalization. Later work needs held-out object/subject
checks, multi-seed Validation, robot-domain adaptation, and matched trained
Cm-on/off policy utility. Rare symmetric-object rotation/tracking discontinuities
are filtered conservatively; no new contact/causal labels are inferred.
