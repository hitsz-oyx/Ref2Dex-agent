# PTv3-Shared-WAM v2

本设计承接会话 `01a1345e-9ca6-7162-b5e9-9ffb09236198` 中用户已经同意的
新 Task 路线。目标是改善三域预训练的交互预测表示与容量分配，继而服务于
MISSION 的机器人自训练与 Cm 增益验证。v2 当前只实现预训练；旧 Task 的660机器人
微调继续运行，机器人迁移和最终闭环需单独验证。

## 数据与单位

复用旧 Task 的 SharedWindows/shared_collate、完整序列 train/val/test 划分、
30Hz/H4/K24、当前 anchor 坐标、物体同身份 query 点及 t+24 goal delta。
现有 loader 提供物理量，不自动标准化输入；v2 不读取旧 scene_mean/std。
输入坐标和H4位移除以0.05m，速度除以0.5m/s，加速度除以5m/s²；法线与metadata
保持原值。这些为固定量纲尺度，不按域或当前batch拟合，不改变 voxel 的米制坐标。

Horizon统计只从TRAIN按 mixed_indices 的 source_weights 与 .6/.2/.2 strata
采样4096窗，分别计算 hand/scene 的24×3位移均值与总体标准差。
统计按有效点聚合，保留三域混合中的实际点数权重；不引入按域标准化。
场景和手分别统计，std下限1mm，只使用有效标签，保存抽样索引、来源与计数。
这近似匹配现有全batch点数加权损失的目标分布，不声称是精确总体统计。
场景motion weighting保持原样，统计本身不额外按motion权重加权。

模型学习 z=(delta-mu)/sigma；损失分别在hand/scene标准化空间计算masked MSE。
公开的 scene/trajectory 输出已还原为米；EPE与goal-only对照均在米/mm中计算。
将来微调必须沿用预训练的这份统计；不能在robot/dev/test重新拟合后当作同一模型。
标准化目标损失不可直接与v1的0.05m标度objective比较，比较预测质量须使用物理EPE。

## 联合点编码

Hand Encoder：当前xyz+H4速度/加速度/位移→128D MLP，加hand-ID与11点语义ID。
该编码同时进入PTv3手点输入与后续显式分支。
场景18D特征使用固定尺度后投影到128D；移除loader中的旧hand行，再按语义追加22点，
避免手点重复。有效性从start_hand_valid取得，缺失点不会作为零坐标参与稀疏聚合。

使用固定1cm voxel和[-2,-2,-2]m原点。每voxel分别求scene/hand特征均值，
concat后线性融合到128D，避免大量表面点冲淡hand编码。PTv3 encoder通道为
64/96/128/192/256，depth为2/2/3/8/3；decoder为128/128/192/256，depth各2。
不迁移旧PTv3-small权重，v2从头预训练。

PTv3输出通过原point→voxel inverse映射回读。场景只取256个几何token；22个手点
按固定hand/keypoint索引独立回读，绕过场景token抽样。碰撞voxel中的几何feature
可以相同，之后每个手点再concat自己的原始Hand Encoder编码，投影为独立shared token。
保持身份的是显式语义分支和独立槽位，不声称PTv3能恢复同voxel内被聚合前的全部信息。

## Shared与预测头

256 scene+22 hand+32 goal，共310 token；分别线性投影到768D，加type/position编码。
12层768D Transformer，12 heads，FFN=3072，dropout=0，激活重计算。
使用原生宽度，不使用旧模型迁移时的整数复制/均值桥。
共享层参数约85M，几何支路参数以实际构造统计为准。
手预测头读22个shared手token；scene query按当前同身份点坐标读全部shared表示。
head内部学习投影到256D，每horizon用time embedding解码XYZ标准化位移。
双头均依赖shared goal；scene损失不依赖hand预测头。

消融开关只在v2配置：horizon_normalization、hand_in_ptv3、explicit_hand。
关闭horizon标准化时使用统一0.05m输出/损失尺度；其他合同不变。

## 实现与检查

独立包ptv3_shared_wam_v2、schema ref2dex.ptv3-shared-wam.v2；旧checkpoint拒绝加载。
checkpoint完整保存配置、统计、model、optimizer、每rank RNG和代码提交；不可覆盖。
训练复用旧有序stateless预取、vectorized padding、bf16、fused AdamW、TF32。
实现文件被修改、出现外部GPU进程、非有限量或资源超界时停止所属运行并保留证据。
当前Probe为2卡×64/global128、1000更新，AdamW全部从头1e-4，不按batch线性放大学习率。
每250步dev，每500步恢复点，保护best/latest。单run8GB、2小时，共享仍400GB与最多6卡。

先检查统计roundtrip、mask/NaN、同voxel密度与语义索引、双头梯度/隔离、真实三域GPU
四步及checkpoint恢复；再运行1000步Probe。不是匹配架构消融，不能据此归因某一项改动；
长预训练预算在真实吞吐与dev检查后再作Decision Note。
