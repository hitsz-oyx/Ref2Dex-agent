# Skill-generated project artifacts

This directory contains project documents produced with repository skills. They are
versioned design and decision artifacts, separate from experiment cards and run
manifests:

- `adr/`: architectural decisions, usually created with the `domain-modeling` skill;
- `specs/`: reviewed design specifications created by the architectural path of the
  `brainstorming` skill;
- `plans/`: implementation plans retained from the earlier planning workflow.

These files explain why a route or interface was chosen. They do not define the current
research state or replace experiment evidence. The current research entry points remain
`docs/MISSION.md`, `docs/STATE.md`, `docs/CAMPAIGN.md`, and `docs/experiments/INDEX.md`.
