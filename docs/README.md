# Ref2Dex 文档入口

新对话只从根目录 [`AGENTS.md`](../AGENTS.md) 和当前研究事实开始。仓库不再维护主代理、
子代理、Broker、固定角色或版本化治理计划工作流。

## 当前入口

* [`MISSION.md`](MISSION.md)：研究问题和最终目标；
* [`STATE.md`](STATE.md)：当前 North-star、已确认事实和下一步；
* [`CAMPAIGN.md`](CAMPAIGN.md)：资源、权限和保护边界；
* [`research/README.md`](research/README.md)：研究记录索引；
* [`workflow/README.md`](workflow/README.md)：唯一运行时工具——容量故障看门狗。

研究证据保存在 `decisions/`、`experiments/`、`handoffs/`、`activities/` 和 `logs/`。
这些记录描述事实，不会自动变成当前规范。`.runtime/` 只保存本机看门狗状态，不提交为
研究证据。
