1. **完成执行模型 \(R\)**  
   训练：
   \[
   R(\tau^{hand}_{future}, s_t)\rightarrow A_{\text{full}}
   \]
   其中：
   - \(\tau^{hand}\)：未来手部关键点轨迹
   - \(s_t\)：当前机器人状态
   - \(A_{\text{full}}\)：完整机器人控制命令，不是 residual  
   先固定已经可用的 wrist 解码，重点完成 finger/contact-conditioned command decoder。

2. **完成 GT 轨迹执行上界**
   \[
   \tau^{hand}_{GT}\rightarrow R\rightarrow A_{\text{full}}
   \]
   在 Gym 中验证完整 episode，确认 GT 手轨迹能够稳定转换成真实机器人控制。

3. **训练轨迹策略**
   \[
   \pi_\tau(H_t)\rightarrow \tau^{hand}_{t+1:t+T}
   \]
   从当前观测/历史 \(H_t\) 直接预测未来手轨迹。

4. **建立完整 trajectory-policy baseline**
   \[
   H_t
   \rightarrow
   \tau^{hand}
   \rightarrow
   R
   \rightarrow
   A_{\text{full}}
   \]
   先验证不使用 PointWorld 和 evaluator 时，baseline 本身能够完成任务。

5. **生成多个 trajectory candidates**
   \[
   H_t
   \rightarrow
   \{\tau_1,\tau_2,\ldots,\tau_K\}
   \]
   候选直接在 hand-trajectory space 中生成，不再在 residual native action space 中生成。

6. **验证 PointWorld 的 trajectory-action 接口**
   对每个候选：
   \[
   (\text{current scene},\tau_i)
   \xrightarrow{PW}
   \hat E_i
   \]
   其中 \(\hat E_i\) 是预测的未来物体运动 / scene consequence。

7. **保留并整理 GT-future oracle evaluator**
   使用真实未来：
   \[
   Q(H_t,\tau_i,E_i^{GT})
   \rightarrow
   score_i
   \]
   验证同一状态下多个 trajectory candidate 的排序能力。

8. **用 PointWorld future 替换 GT future**
   \[
   Q(H_t,\tau_i,\hat E_i)
   \rightarrow
   \hat score_i
   \]
   检查 PointWorld 预测后果是否能够保留 GT-future evaluator 的候选排序能力。

9. **完成 trajectory candidate selection**
   \[
   \tau^*
   =
   \arg\max_i
   Q(H_t,\tau_i,\hat E_i)
   \]

10. **执行选中的 trajectory**
    \[
    \tau^*
    \xrightarrow{R}
    A_{\text{full}}
    \]
    执行短时间后重新观测。

11. **组成滚动 imagined MPC**
    \[
    H_t
    \rightarrow
    \{\tau_i\}
    \rightarrow
    PW
    \rightarrow
    Q
    \rightarrow
    \tau^*
    \rightarrow
    R
    \rightarrow
    A
    \rightarrow
    H_{t+\Delta}
    \]
    然后重复规划。

12. **最终对照实验**
    比较：
    \[
    \text{原 baseline}
    \]
    \[
    \text{trajectory-policy baseline}
    \]
    \[
    \text{trajectory-policy + direct evaluator}
    \]
    \[
    \text{trajectory-policy + PointWorld imagination + evaluator}
    \]
    以最终任务成功率作为主要指标。
