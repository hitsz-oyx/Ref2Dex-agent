## 建立反向隧道

在 **Windows PowerShell** 执行，并保持终端和 Windows 网络连接：

```powershell
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=10 -R 127.0.0.1:22023:100.64.0.23:22 RLG
```

`-R` 在 RLG 的 loopback 地址监听端口，由 Windows 连接目标地址；Windows
不需要额外启动 SSH server。端口仅供 RLG 本机连接。正常时没有持续输出；
按 Ctrl+C 结束隧道。Windows 睡眠、断网或关闭窗口后，需重新运行。
`ExitOnForwardFailure` 确认监听建立，并不保证每次能连上目标 SSH。
参见 [OpenSSH ssh(1)](https://man.openbsd.org/ssh#R)。

## 登录认证与主机身份

反向隧道不转发 Windows 私钥或 SSH agent。本次成功使用 RLG 已有的
`/home2/wyy/.ssh/id_ed25519` 登录。若以后需要重新授权，可在 Windows 执行：

```powershell
ssh RLG "cat ~/.ssh/id_ed25519.pub" | ssh 4-4090_tailscale "umask 077; mkdir -p ~/.ssh; tr -d '\r' >> ~/.ssh/authorized_keys"
```

该命令追加公钥，不复制私钥；不要反复追加同一公钥。公钥认证说明见
[OpenSSH authentication](https://man.openbsd.org/ssh#AUTHENTICATION)。

本会话首次连接采用 `StrictHostKeyChecking=accept-new` 保存目标主机键，
随后以 `StrictHostKeyChecking=yes` 重复登录成功。首次记录属于 TOFU，
未另外经 Windows 比对指纹。当前 known_hosts 位于本地、未纳入 Git 的
`/home2/wyy/oyx_ws/ai_ws/Ref2Dex-agent/tmp/ssh-4-4090/known_hosts`。
若端口被转发到其他机器，应核对主机指纹，不关闭身份校验。

RLG 上复用已验证的入口：

```bash
ssh -p 22023 -i /home2/wyy/.ssh/id_ed25519 \
  -o IdentitiesOnly=yes -o BatchMode=yes -o ConnectTimeout=10 \
  -o StrictHostKeyChecking=yes \
  -o UserKnownHostsFile=/home2/wyy/oyx_ws/ai_ws/Ref2Dex-agent/tmp/ssh-4-4090/known_hosts \
  wbcd@127.0.0.1 'hostname; whoami; df -hT /mnt/ugreen_nas'
```
