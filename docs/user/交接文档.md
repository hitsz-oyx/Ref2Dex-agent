最近主要涉及下面几个 task(Ref2Dex-agent/src/task)：

1. `ptv3-shared-wam`
这是现在新开的 Shared-WAM 主线。核心是 PTv3 scene tokens + hand tokens + endpoint-delta goal tokens 一起进 shared interaction transformer，然后并行预测 scene future 和 hand future。已经接通三域预训练、robot joint finetune、Chunk-R 和 K=1/4/8 chunk execution，目前工程 smoke 都过了，下一步就是正式跑 OakInk2/GRAB/ARCTIC 三域大训练。

2. `goal-point-wam`
这是之前的 WAM 主线，做过很多 actor / World / goal / control-context / visited-state realignment 实验。现在主要作为历史 baseline 和一些数据处理工具保留，新架构不准备继续在这里堆修改。EgoDex 的 full reconstruction、object-goal、video point 相关脚本目前也有不少放在这个 task 下面。

3. `trajectory-policy`
主要负责机器人执行和策略侧，包括 Chunk-R、native bridge、执行审计以及最近的 residual PPO。现在 PPO 是冻结 WAM + old Chunk-R，只训练 12D native residual。短 Probe 跑通但还没有稳定抓取，长训正在修 phase reset 和 WAM 多 env batch inference。

4. `pointwam-repro`
主要是 PointWAM 的复现和数据合同验证。已经接过 Mosaic3D / Recap-CLIP / Volt-H 的工程路径，也做了 EgoDex clip contract、缩小版 forecaster fit 等实验。这个 task 主要用来核对 PointWAM 原方法，不是当前最终模型实现。

5. `cm-pointflow-effect-pretrain`
这是之前 PointWorld / point-flow / multi-source 预训练以及 PointWAM-style human data pipeline 的主要位置。OakInk2/GRAB/ARCTIC 的现有三域数据、MixedWindows、PointWorld checkpoint、EgoDex 小规模 VGGT-Omega + CoTracker pipeline 都从这里积累下来。现在 `ptv3-shared-wam` 会继续复用这里的数据和 PTv3 权重。

6. `consequence-evaluator`
这是之前做 oracle / evaluator / candidate ranking / Gate1 的 task，里面还有不少 native replay、same-state、candidate effect、ACT chunk 等实验。当前主线基本暂停，不建议继续往这里扩，除非后面重新做 World/evaluator-based action selection。

现在总体关系大概是：

`cm-pointflow-effect-pretrain`
→ 提供三域数据、PTv3/PointWorld基础

`ptv3-shared-wam`
→ 当前新的 supervised WAM 主线

`trajectory-policy`
→ 机器人执行、Chunk-R、Residual PPO

`goal-point-wam`
→ 旧 WAM 主线 + 一部分 EgoDex/goal 工具

`pointwam-repro`
→ PointWAM 原方法复现和对照

`consequence-evaluator`
→ 旧 evaluator/oracle 路线，当前暂停

目前最值得接手继续推进的是 `ptv3-shared-wam` 的三域正式训练，以及 `goal-point-wam` 下面 EgoDex 数据处理向 Shared-WAM 数据合同的适配。
