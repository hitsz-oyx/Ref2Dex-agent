- 发现时间：2026-10-17 02:26 CST。远端 `progress.json` 显示该 run 约第 3758 轮、已用

- 运行器在达到 `seconds` 时会终止 child 并将 run 标为预算终止，因此按当前吞吐它将在约
  7200 秒附近停止，实际只完成约 4700 轮，不会达到 manifest 中的 10000 iterations。
- 风险：若后续实验卡、checkpoint 或对外汇报把该 run 标为“10000 iterations 完成”，会造成
  训练剂量和结果不可复核的致命记录错误。必须以远端最终 `process.json` 的 `status`、
  `exit_code/reason` 和最终 `progress.iteration` 为准，并把它作为截断的 warm-start Probe。
- 最终核验：`process.json` 已为 `status=FAILED`、`exit_code=-15`、`reason=TIME_BUDGET`、
  `elapsed_s≈7208`；实际只到约 `iteration=4734`。由于 child 被 wall-time 强制终止，
  `progress.json` 仍残留 `status=RUNNING`，所以不能把 progress 文件单独当作完成证据。
