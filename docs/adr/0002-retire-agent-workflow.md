# 采用单会话研究工作流

用户于 2026-10-01 决定废弃 root/worker、Agent Broker、固定角色和动态子代理。当前会话
直接承担研究决策、实现和验证；容量故障只由独立的本机会话看门狗按最近 24 小时更新时间
扫描并向原 thread 每 60 秒排队一次 `继续`。这样保留了历史研究证据，同时移除了多套身份、
租约、任务队列和生命周期状态造成的重复规范。

## Consequences

旧 Broker 脚本、registry、worker handoff 和 workflow 规范不再是当前运行时；看门狗只读
Codex 元数据和 rollout，不能创建代理、解除用户暂停或修改研究状态。
