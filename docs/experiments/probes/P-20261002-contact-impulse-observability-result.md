# 接触作用与相对几何：离线检查结果

按[冻结问题与判定](../../decisions/D-20261002-contact-impulse-observability.md)，
端点净力作为整个控制周期平均作用力的接法 `UNPROMISING`。
只处理fit/cal；不读取held指标、不拟合模型、不启动仿真。

fit选择两端平均力估计器，cal5190动态帧上速度向量RMSE61.668m/s，
常速度仅.2946m/s；pre/post力估计也失败。独立float64逐步复算通过，
相对误差3.47e-8。cal原始force中位2.025N（约79.6倍物体重量），
实际速度增量中位.107m/s，端点力预测误差中位22.918m/s；差异不只是少数
异常值造成。实际质量.002593613kg、dt1/30秒、contact_collection2/substeps4。
这些数据不能定位精确原因，也不否定之前静态mg单位检查；动态端点采样、
求解器效应和完整周期力积分尚未辨明，不乘一个事后缩放系数追门。
见[原结果](P-20261002-contact-impulse-observability-r1.json)和
[独立审计](P-20261002-contact-impulse-observability-audit.json)。

下一轮候选监督改为实际周期速度增量；m*(delta-v-g*dt)只能称有效非重力
冲量，包含未分辨的阻尼/求解器作用，不能当作已经分离的手物接触力真值。
任务相关高度、间隙和接触保持仍需真实转移监督与闭环验证。

另已核对可用于结构化Cm的当前相对几何：native原始1442观测中的手部link
位置和物体位置在同一heading frame，可以构造物体坐标下的掌部与五指端
位置。29110个fit/cal真实pre-step观测复算：重复位置0误差、物体速度
坐标变换最大3.81e-6、旋转正交4.41e-6、变换不变性3.58e-7；工程通过。
这些是link原点，不能称精确接触点，也没有证明新Cm预测或控制收益。
见[相对几何工程审计](P-20261002-object-relative-contact-geometry-r1.json)。

只在固定专家目录中评分；模型合同、候选生成与停止条件须在拟合前固定。
