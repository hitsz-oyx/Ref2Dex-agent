# Candidate boundary: recover physical commands rather than arbitrary coordinates

The native18-dimensional interface has six overwritten dependent commands.
This creates exact, code-verifiable action equivalences. It is different from
merely distant or currently inactive hand motions, which can affect later contact.
No noisy threshold is called a transitive equivalence relation.

Let action A=(U,N), where N is independently randomized and absent from the
actuator target mapping. For current physical state S, the true successor Y has
`Y independent of N conditional on (S,U)`. With E[N]=0 and Var[N_j]=1,
`E[(N_j-g_j(S,Y))^2] >= 1`. A learned predictor can circumvent this physical
bound by encoding N into its *predicted* Y. Testing inverse error together with
the counterfactual null response distinguishes this behavior from truthful
predictor-level action retention. This elementary argument is a hypothesis
generator, not a novel sufficient-representation theorem or an impossibility
claim for inverse learning in general.

[AD-WM](https://arxiv.org/html/2609.30264v2) recovers actions from generated
transitions to improve planning. Our small physical MLP experiment only tests
that objective's boundary under known redundant coordinates; it is not a
reproduction or refutation of AD-WM's image-based experiments.
[Learning Action-based Representations Using Invariance](https://arxiv.org/abs/2403.16369)
already develops controllability representations. A command quotient alone
would be an incremental application, requiring a consequential additional
method and task evidence for a journal-level contribution.

[Contact-UAN](https://contact-uan.csail.mit.edu/) already combines contact-consistent
replay and actuator residual learning for humanoid transfer. Actuator correction
or accurate replay alone is therefore not an original contribution here.

The prefit mechanism design is
`docs/experiments/probes/P-20261001-null-action-recovery.md`. Its decision is
whether to pursue physical canonicalization when adding inverse regularizers,
not whether to publish the general known conditional-variance bound.
