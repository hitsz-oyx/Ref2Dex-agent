# Archived research governance records — 2026-10-04

This directory preserves the former research queue, deferred-evidence ledger,
activity records, and decision memos after the repository moved to a smaller
single-session documentation workflow.

The files are historical evidence. New work is recorded in experiment cards,
run manifests, Git commits, and the active seed policy. The archived records
are intentionally not consumed by the active verification gate.

The former `docs/handoffs/` directory is preserved at
`docs/archive/2026-10-04-research-governance/handoffs/`. Its Markdown, JSON, and audit
scripts are retained as historical provenance; no new worker handoffs should be added there.
The former `docs/workflow/` directory is preserved at
`docs/archive/2026-10-04-research-governance/workflow/`; it is no longer an active
watchdog or research workflow entry point.
The former root `docs/logs/` directory is preserved at
`docs/archive/2026-10-04-research-governance/logs/`. These files are historical
provenance; new runs should use experiment cards and run manifests.
