# Decision: predict vector effects instead of assuming a monotone lift response

The fixed pulse screen is UNPROMISING under its full predeclared gate: the
plus-minus world-z effect is not positive in every panel. This result and gate
are preserved. No policy-lift claim follows from the experiment.

At the same time, its separate physical-resolution component passes clearly:
at horizons5/10, full position contrast RMS is7.15/18.83mm, versus repeated-zero
response differences0.10/0.44mm. Thus the data distinguish a measurable physical
action effect from a reliably beneficial lift effect. The current limitation
is directional/task interpretation, not an absence of physical contrast.

Choose one fixed vector-response learning Probe using the already-collected
data. Predict all three displacement coordinates at5/10steps and compare
contrast error against factual/no-pulse models and fit-mean controls. This
supersedes the unexecuted conditional learning design's requirement that the
whole monotone-lift screen pass. The learning gate retains>=10% improvement over
factual/global-mean controls and>=75% agreement with the *measured* z sign;
it never requires all true effects to be positive. No physical threshold or
original label is changed, and no simulation is rerun to chase the old gate.

Budget: GPU4 after release,<=10minutes,<=100MiB; three fixed optimization seeds,
no tuning or endpoint selection. Failure stops this small-data vector model.
A positive result would justify broader geometry/contact-conditioned collection,
not a controller or journal claim. Test panels were included in the physical
diagnostic, so all learned results remain exploratory reused-data evidence.
Current user authorization covers this reversible standalone research step.
