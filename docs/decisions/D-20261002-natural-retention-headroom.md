# Decision: examine natural retention failures before designing feedback control

The first actual return-trained Cm/state/global comparison fails. All three
heads choose identical deterministic actions on1536 states. Stop that exact
feature-transfer recipe. More static fitting cannot be justified by different
success counts from different randomized cohorts. The nominal position and
finite external-impulse recipes also stay closed.

Higher-level alternatives: alter the initial object distribution to create new
contact regimes; model hidden material parameters; or replace the single pre-lift
decision with feedback during natural support loss. Choose to inspect the last
alternative FIRST because retained native traces can answer a necessary condition
without new simulation, material changes, or training. This keeps the mission:
action-conditioned short physical transitions must eventually improve training.
It does not supply a novel method or positive result by itself.

Decision question: among unchanged-actor trials, do failures occur after the
object has already achieved at least five consecutive physically lifted ticks,
leaving an interval in which feedback recovery could act? If essentially all
failures precede acquisition, a retention-recovery route is poorly grounded.

Cheapest method: descriptive CPU statistics on the12 fresh training panels'
randomized arm0 cohorts, without touching future evaluation panels or fitting a
model. Use the ORIGINAL rise30mm and full-mesh clearance20mm; five consecutive
ticks define preliminary acquisition only, never replace physical105. Report
per-motion acquisition, subsequent loss, first-loss timing, and observable
relative downward speed20mm/s AFTER acquisition. These are descriptive,
reused-data counts, not policy utility, causal action contrasts, or Validation.

At most120s and10MiB; no GPU model computation, physics, state writes or new
external boundary. Use a unique output and source hashes. Meaningful late-loss
headroom permits a prospective bounded native recovery Probe with fixed event
timing and strong feedback controls. Absence redirects to acquisition/decision
representation instead. No force-amplitude, pose-range, or optimizer scan.
