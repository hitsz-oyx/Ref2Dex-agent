2026-10-01。用户最新方向：先设计并检验 Cm 对可执行接触动作的短期后果排序，
再考虑完整抓取收益；允许讨论新的作用机制，保留已关闭 HF08 的全部证据。

及 `scripts/run_cm_physical_value_environment.py`。损失还按 sigma 归一化，训练系数

足够的策略影响；弱路径是待检验解释，不能据此认定它造成了失败。

## 选择的作用链条

当前状态与短历史 + 可执行候选动作/控制片段
→ 非线性动作条件 Cm 预测短期物理后果
→ 基于接触支持抬升、接触损失和掉落风险排序
→ 在可靠优势时直接执行所选动作的第一步/短片段
→ 新观测后再次决策；不确定时用 base。

第一阶段不使用长期 V，不以辅助 loss 的存在代替动作影响。预测目标先固定10步，
不同时扫描10/20/horizon。定义候选的执行时长与后续 base continuation，模型和
采集必须一致：例如执行候选2步、随后 base8步，其标签不能拿“专家连续执行10步”
的旧记录替代。若候选指闭环专家 option，必须用专家身份/控制器描述条件化，
不能把当前一个动作冒充其未来10步变化；未来真实动作不得泄漏到决策输入。
六专家只是候选来源，需要验证它们在当前接触状态的可执行性和有效差异，
不能因为旧专家能抓别的物体就假定其动作对 airplane 有用。

## 最小可判别顺序

1. **候选机会与局部噪声先行**。少量接触前历史，base重复与候选真实执行，
   记录固定10步接触支持抬升、接触保持/损失及已抬升状态的掉落。
   检查候选是否存在超过 base重复噪声的可利用差异；若候选没有优势，
   改善候选/执行片段，不通过放大监督系数期待模型创造收益。
   仓库 paired evaluator 仅验证冷初始状态，拒绝热 PhysX 恢复。分支收集优先
   从同一冷状态重放相同接触前动作历史，检查触发状态的差异并保留 base/base
   噪声；不把仅复制 root/DOF 的热状态宣称为精确反事实。
   若预历史仍不能在所需局部分辨率内匹配，改用已知 propensity 的随机干预，
   报告群体策略价值与区间，暂不报告逐状态真实 regret。
2. **再检验可学排序**。按原始 episode/状态组划分 fit、calibration、holdout，
   同状态的候选、重复和轨迹必须同 split。Cm 预测任务相关物理后果，避免
   只回归终点成功标签或仅根据专家 ID 学全局偏好。与相同历史的 state-only、
   action-shuffled、always-base 及 fit-only最佳固定候选对比；shuffled 必须真正
   破坏 fit 中动作—后果对应，不能只是全局交换候选名字。冻结 fit/calibration
   的阈值后报告真实执行 uplift、排序、regret（仅有分支真值时）、介入覆盖率，
   同时报全部状态和介入子集，防止只靠 abstain 得到虚假的可靠性。
3. **短闭环机制检验**。排序有效后才让 selector 连续重新观察并执行，记录
   候选选中率、相对 base 的实际动作差异、接触/抬升/掉落后果和推理延迟。
   单次 contact option 的优势不能自动升级为 receding-horizon 控制收益。
4. **再进入学习与终局评价**。闭环可靠后单独设计 actor训练接法与匹配对照；
   不将覆盖 actor 输出后的行为动作仍按原 actor logprob 做普通 PPO 更新。
   最后用完整稳定抓取及后续掉落验证；冻结控制器收益本身不完成 Objective B。

下一项 Decision Probe 要区分“候选没有可利用优势”和“优势存在但当前模型不能排序”。
最便宜的方法是先收集少量真实候选后果，而不是继续训练 V、增加 PPO epoch 或
直接跑整个终点矩阵。先限定 airplane 与既有自训练专家；建议第一项机会 Probe
最多32个接触状态，覆盖三条 motion，base重复及全部有效候选，预算单空闲 GPU、
总60分钟/8GiB以内。正式运行前固定动作片段、接触代理、物理目标、局部噪声判据，
登记独立 family/实验卡；本记录不消耗 HF08/HD02 已用 slot，也不启动任何进程。

## 边界与停止条件

保留 HF08/HD02 UNPROMISING 和实现关闭事实，不据此反驳 Cm 核心假设，也不把
本设计称为已经有效。候选真实执行和标签合同失败则修复合同；没有可分辨的动作
优势则停止该候选集合；有优势但排序失败则聚焦表示/覆盖而非立刻投入 RL；
覆盖不足或副作用超过收益则不进入学习。无需变更 MISSION claim、资源上限或
外部权限。旧 checkpoint/数据均只读保留；模型拟合、批量推理和仿真优先单 GPU，
本次仅做源码/文件数据审计，使用 CPU，无训练或新数据采集。
