# Airplane 物理模型与长期价值路线决定

当前决定是是否将新的 Cm 探索从位移排序或冻结辅助标签，转为短期物理预测与长期价值结合，并最终用于策略训练。用户认可该机制、airplane 首次验证、任务相关共同奖励、持续保持评价，以及外部数据预训练可选的边界。

关键证据是局部动作物理效应可学，但旧加权、辅助表示、直接动作价值和 BC 输入未建立稳定策略收益。现有完整 airplane 转移可复用，reward 与终止合同仍需新采集；源策略已包含抓取 shaping。新路线没有已运行的正向结果。

root 选择完整轨迹数据上的一步模型加长期 value 候选监督，保留原 actor 环境采样和 PPO，比较普通 PPO、直接 Q 监督与 Cm-value 监督。理由是显式利用预测后果，又避免更换行为动作后仍按旧 logprob 更新 PPO。

拟定成本为两 GPU、六小时内、20 GiB，不突破 Campaign；超默认短 Probe 的理由是规模和完整时序本身是待检验变量。正向后优先正式 Validation，负向停止实现，合同失败或预算不完整不作科学负向。具体设计见 [设计文档](../superpowers/specs/2026-09-30-cm-physical-value-design.md)。

当前状态是设计待审阅，尚未授权该具体设计的实施阶段。无新增外部写入或系统权限要求。
