# 把 Cm 移到接触至抬升的控制阶段

需要决定：是否继续已抬起后的局部目录优化，或让Cm预测尚未建立离桌抓取的
短片段后果。HF16一步信息PROMISING且真实控制胜state-policy，但未胜强fixed；
HF17强控制周围的修正1506窗口，fit选中7的held收益−9.227mm，原门失败。
这些负结果全部保留，不把它们当作Cm核心假设反证。

已知实现限制：当前介入条件要求中心rest+3cm且源meshCLR2mm，因此物体未
抬起来时Cm没有控制权。这是代码事实，不是已证明的失败原因。选择HF18：
接触存在代理下、尚未满足离桌门的状态；预测实际10步反馈控制律的height/
CLR/净力存在/支持抬升/clear-to-loss等任务相关后果，目标不依赖长期V。

先复用HF15原3917完整随机程序窗口，检查early held的正负监督支持；不足
就不拟合，转新定向随机采集。足够才GPU拟合9个匹配模型：Cm/state-only/
action-shuffled各3seed11601–11603、1000updates/batch256。输入只有pre-history、
pre-nativeobs、pre原始力、当前真实12独立PD目标减pre-q，以及已知反馈控制律
（六专家identity+是否全片段旋转锚定）。未来专家命令不输入模型；预测明确
条件于固定控制律，而非声称仅第一步命令决定未来全部轨迹。保持源数据的
10步反馈执行合同，后续直接控制也按短片段执行后重新观察，避免预测/执行
控制律不一致。state-only移除motor和控制律，shuffle将二者成对打乱。

HF18预算2 Probe，各<=60min/8GiB；slot1先数据资格再H10物理信息，所有训练/
失败/审计合计。整初始组fit/cal/held与原9851划分一致，探索holdout已被用于
路线选择，不能称未经研究者观察的正式Validation。原HF16模型/门限不改。
slot1信息门在拟合前冻结，见实验卡；正向才slot2直接接触到抬升选择，和强
状态策略/动作打乱/base/fit固定程序比较，真实控制通过才策略学习。失败则
复盘接触状态观测与可执行动作生成，不增加同配方epochs/seeds追门。
Mission/C3/机器权限不变，无新增外部授权边界；GPU优先，C3仍OPEN。
