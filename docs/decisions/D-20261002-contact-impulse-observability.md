# 接触作用链条：先核对力与真实速度增量

问题：下一轮Cm应直接监督日志中的净接触力，还是监督一个控制周期内的接触
冲量？HF18完整H10控制律模型在早期状态未过原轨迹信息门；不降低门槛，也不
继续同配方训练。此前一步Cm有信息，仍未胜强固定程序，C3继续OPEN。

选择一个Decision级离线检查：复用已审计HF15和HF18随机片段，只读fit/cal；
物体未被额外施力，控制周期2×1/60秒，日志只有周期端点的净接触力。
检验Newton速度更新v_next=v_pre+dt*(F/m+g)。pre、post及两端平均力三种
无拟合估计器，仅fit选误差最小者，再在cal检验；不改力单位或拟合缩放系数。
动态帧定义|v_next-v_pre|>.05m/s，另保留全帧及early统计。

原判定：cal动态帧至少500；所选估计器速度向量RMSE比常速度至少低20%，
才将端点力作为下一步物理解码的候选监督。失败则放弃“端点力就是周期平均
接触力”的接法，考虑J=m*(v_next-v_pre-g*dt)这一实际周期冲量标签；还须
工程核对相对手物几何及可执行候选，不能据此宣称Cm或控制收益。

预算10分钟/64MiB，无NN拟合/推理或新增仿真，CPU纯统计符合GPU优先规范。
不读取held指标、不改旧checkpoint/输入，不更改Mission或claim，无外部授权。
此检查不是新增utility family，也不重置HF18预算；后续模型另行固定合同。
