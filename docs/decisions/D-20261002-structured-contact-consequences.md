# Decision Memo：结构化接触后果与参考附近的动作效果

当前问题：应先补生成器的保持惩罚，还是先改后果模型？核心Mission/claim和
最终matched策略学习验收不改，C3和完整机制goal保持OPEN/ACTIVE。

关键证据：HF20真实生成控制已有16/23留出Cm窗口改变PD，但未证明超过强cup，
原门UNCLEAR且均不通过。HD03仅cal306重放发现预测接触保持普遍提高而非降低，
支持抬升概率55窗口超过其必要的手/物存在概率，22窗口超5pp；平均预测增益
2.216mm、事实高度MAE23.940mm，存在动作信息但可靠差异决策仍未证。
完整原生/规划/预测/标签/统计审计通过，未发现实际控制未执行的接线错误。

选择：下一轮先做可丢弃的结构化后果原型，补全事件与动作效果的学习合同。
不把旧独立输出的概率直接叠加成新惩罚，也不放宽HF20原门。候选输出以末3步
hand/object存在及几何clear的8种联合事件分布表达，不假设三个事件独立；支持
事件是联合111，支持抬升概率由该概率乘条件抬升概率构成，期望支持高度由该
概率乘非负条件高度构成。先用标签合同和工程证明包含关系，再测实际预测信息。
额外编码当前六专家动作bank、cup参考PD差和可观察的当前原生参考状态，避免
只凭原始动作权重解释未来反馈。输入只接受当前观测、当前候选和已知控制律。

最便宜下一步：复用审计HF19/HF20源，原分组fit-only训练与归一化；cal只用于
诊断，held不用于调参。匹配state-only、action-shuffled与直接评分的容量/更新
预算，并保留不学习的参考。旧held已用于先前研究，只能作复用数据的机制screen，
不能充当新独立Validation。新收益判定必须另采独立随机执行源，仍无逐状态oracle。

模型Probe单空闲GPU、<=1800秒/512MiB，无新仿真。工程不代表模型信息改进；
