# Decision Memo：先识别原生动作响应，再扩展模型容量

HF21–22绝对后果/接触信息改善未带来强控制收益；HF23风险约束实际失败；HF24
速度反馈相对base+22.434mm但强Cup+6.415mm区间跨0、噪声门未过。旧配方关闭，
不调整门，也不为固定gain0.5程序追加Cm拟合或PPO。问题转向当前随机动作是否
提供可识别的物理增量，而非再生成一个固定目录或只比较绝对后果MAE。

选择复用已审计HF19源，限定原fit/cal，仅第一实际控制周期。已知8候选PD与
随机分配概率，构造z=actual_PD-E[PD|current_candidate_set]；E[z|当前候选集]=0。
使用当前状态的基线响应，加几何/运动条件的线性动作响应G(s)z，显式分离
状态漂移与动作对比。真实速度/位移/mesh变化作监督，重力/CV只作确定先验；
不积分端点接触力、不称有效速度响应为已分离的手物冲量。

这是新物理响应表示的最便宜资格检查，不是重开HF24候选配方或HF16六标量
任务头。若简单响应已经能在cal保留动作信息，下一步才设计更丰富的响应模型
及约束动作生成；失败只关闭此小型线性响应配方，不否定所有非线性Cm。
完整goal仍需可靠候选、Cm与全部控制的排序、实际再决策和最终策略验收。

固定诊断预算300秒/64MiB/单空闲GPU5（线性拟合及批量模型计算也用GPU）；
不新增仿真、不读held目标、不选超参。源复用成本单列，fit/cal组不混合，
参数/归一化/统计审计与停止条件在独立诊断卡冻结。无外部授权需求，C3OPEN。
