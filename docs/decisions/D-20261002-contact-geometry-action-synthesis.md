# 下一版Cm：绑定手指动作与相对几何，并生成可执行修正

问题：继续给固定专家目录评分，还是让Cm直接预测关节动作怎样改变手物
局部相互作用，并据此生成受约束的修正？选择后者；Mission及最终claim不变。

证据：HF16一步物理信息存在，但未超过强rotation_cup；HF17固定修正无正向
机会，HF18完整H10控制律的early轨迹信息门失败。不能把负结果解释为Cm
核心思想失败。29110个pre-step相对几何工程通过；端点净力不能当作周期
平均力，不能直接用F/m积分作为解码器。

设计选择：按掌部/五指组织当前物体坐标下的相对位置与运动，为各指绑定其
当前关节和真实原生PD目标，学习下一控制周期的相对几何变化、物体实际
速度/位移变化、间隙和接触保持。速度增量扣重力后的量只是有效作用标签，
不冒充已分离的手物接触力。保留观测历史以处理接触切换；未来只作监督。

动作来源改为冻结六专家反馈之间的受约束组合，XYZ与手指分别组合，腕部
旋转锚定沿用已有正向控制职责。保存组合系数、逐步反馈和全18个实际PD目标；
不依赖随机±0.1，也不对旧数据外推混合动作真值。先收集随机组合的真实
短片段作为适配监督，重复强rotation_cup作为随机噪声参照。短周期重新观察
与执行器映射必须一致；最终H10收益用真实重新决策片段检验，不用预测轨迹
代替实际收益，也不把短期收益直接称稳定抓取。

拟合前冻结新卡：模型与动作打乱/无动作信息匹配，utility另有直接任务评分
策略及强固定程序，避免把退化的state-only物理模型当唯一策略对照。候选
生成共享同一可执行域、计算预算和不确定回退；不让优化器任意外推到无
随机监督的关节范围。新数据分组留出，不用已看过的held作为正式Validation。

预计下一路线两Probe，各≤60min/8GiB、默认单GPU；先监督/动作域资格及
物理作用信息，正向才实际闭环控制。资格不足补最小监督而非先训练；物理
作用或真实控制无增益则停止当前配方，不扫描比例、seed和门槛。通过以后
才接入策略训练和最终保持/掉落验收。目前尚未登记或启动新训练/仿真。
