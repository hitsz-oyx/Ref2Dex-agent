## 状态定义

| 状态 | 含义 |
| --- | --- |
| `VALID` | 实现与预注册配方一致，具备该实验声称所需的执行证据 |
| `INVALID` | 实现、输入或 provenance 与目标配方不一致，不能作为该配方的科学反证 |
| `PARTIAL` | 局部合同通过，但范围不足以支持完整方法结论 |
| `REPLAYABLE` | 保存的信息足以独立重算关键决策或指标 |
| `DERIVED_ONLY` | 只能核对派生结果，无法从保存物独立重放完整决策 |
| `NOT_REPLAYABLE` | 缺少重算所需的输入、成员预测或原始产物 |
| `POSITIVE_LOCAL` | 局部机制或信号成立，不等于最终策略收益 |
| `NEGATIVE_VALID` | 在明确限定的有效 recipe、数据和预算下，负结果成立 |
| `INCONCLUSIVE` | 证据不足以判断有效性，或支持/区间门未达到判别要求 |
| `INVALID_IMPLEMENTATION` | 实现错误使该实验不能检验原目标配方 |

预算决定（`CONTINUE`、`PAUSE`、`STOP`）独立于科学状态；停止投入不自动等于方法被否定。
